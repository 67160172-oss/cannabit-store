# ใบเขียว: ร้านกัญชาและคลังความรู้ (ต้นแบบ)

จัดทำโดย นาย พชรพล พรหมมา 67160172

## วิธีเปิด
- **หน้าร้านค้า**: ดับเบิลคลิก `index.html` เพื่อเปิดในเบราว์เซอร์
- **หน้าจัดการแอดมิน (หลังบ้าน)**: ดับเบิลคลิก `admin.html` หรือกดปุ่ม "⚙️ แอดมิน" จากแถบเมนูด้านบนของหน้าร้าน

## โครงสร้างโฟลเดอร์
- `index.html` หน้าร้านค้าหลัก (Header, Age Gate, พื้นที่แสดงผล, Dialog)
- `admin.html` หน้าแอดมินเต็มรูปแบบ (Dashboard สรุปยอดขาย, จัดการสินค้าและสต็อก, ตรวจสอบและเปลี่ยนสถานะคำสั่งซื้อ, พิมพ์ใบเสร็จ, จัดการสมาชิกและการตรวจอายุ 20+, คลังความรู้)
- `css/style.css` สไตล์หน้าร้านค้า รองรับโหมดสว่าง/มืด และอุปกรณ์มือถือ
- `css/admin.css` สไตล์หน้าแอดมิน พรีเมียมธีมมรกต-ดาร์กโหมด พร้อมระบบพิมพ์ใบเสร็จ (A4 Print)
- `js/data.js` ชั้นข้อมูลจำลองแทนฐานข้อมูล 5 ตาราง (Users, Products, Orders, Order_Items, Articles) เก็บใน localStorage
- `js/app.js` ระบบหน้าร้านค้า ฝั่งลูกค้าและการสั่งซื้อ
- `js/admin.js` ระบบแดชบอร์ดแอดมิน จัดการสินค้า สต็อก ออเดอร์ ใบเสร็จ และสมาชิก

## บัญชีทดลอง
- ลูกค้า: customer@demo.th / demo1234
- ผู้ดูแล: admin@demo.th / admin123
*(หน้า admin.html มีปุ่ม "เข้าสู่ระบบแอดมินทันที" สำหรับทดสอบได้ใน 1 คลิกโดยไม่ต้องพิมพ์รหัสผ่าน)*

## หมายเหตุ
ข้อมูลเก็บใน localStorage ของเบราว์เซอร์ที่เปิด กดปุ่ม "รีเซ็ตข้อมูลตัวอย่าง" ท้ายเว็บเพื่อเริ่มใหม่
ระบบนี้เป็นต้นแบบเพื่อการศึกษา ไม่มีการขายสินค้าจริง
